# Clueless

MS AI School 팀 프로젝트의 MVP 개발을 위한 저장소입니다. 프런트엔드, 백엔드, ML 작업 공간과 문서를 분리해 관리합니다.

## 폴더 구조

| 경로 | 역할 | 현재 상태 |
| --- | --- | --- |
| [`frontend/`](frontend/) | 사용자 화면 | Vite + React + TypeScript 구성 완료 |
| [`backend/`](backend/) | API 및 서비스 로직 | Spring Boot 사용 예정 |
| [`ml/`](ml/) | 데이터 처리, 모델 학습·평가 및 추론 | Python 사용 예정 |
| [`docs/`](docs/) | 요구사항, 설계 및 협업 문서 | 문서 공간만 준비 |

프런트엔드는 개발 환경을 구성했습니다. 실행 방법은 [`frontend/README.md`](frontend/README.md)를 참고하세요. 백엔드와 ML은 아직 스캐폴드를 구성하지 않았습니다.

## 파일 관리

- 비밀값은 커밋하지 않습니다. `.env`와 `.env.*`는 제외하며, 실제 비밀값이 없는 `.env.example`만 공유할 수 있습니다.
- 원본·가공 데이터는 각 작업 공간의 `data/raw/`, `data/processed/`에, 업로드 파일은 `uploads/`에 두고 Git에서 제외합니다. 모델 가중치는 `weights/`에 둡니다.
- `.gitignore`는 데이터 파일 확장자 전체를 차단하지 않습니다. 공유 승인을 받은 작은 예제 데이터는 위 제외 경로 밖에 두고, 라이선스·개인정보·공개 가능 여부를 확인한 뒤 추가합니다.
- 저장소가 공개되어 있으므로 커밋 전 비밀값, 개인정보, 데이터 및 모델의 공개 권한을 확인합니다.
